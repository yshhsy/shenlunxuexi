申论零基础 · 合格路线图

第一课 · 认清申论
申论不是写作文，而是「带着任务的阅读理解 + 有格式的抄材料」。一张卷里小题（归纳概括、综合分析、应用文）占 60 分左右，答案几乎全部藏在给定资料里；大作文只占 40 分，且二类文（24 分上下）就已达标。合格策略：把小题拿到 70-80%，大作文保住二类文，申论就能过 60 分。所以完全不会写作文也没关系——先放下对「文采」的恐惧，申论考的是找点和整理，不是文采。
第二课 · 小题四步法（拿分基本盘）
第一步 审题：圈出作答对象（做法？问题？原因？变化？）、材料范围、字数。对象决定你回材料里找什么。第二步 找点：逐段读材料，只标记动词短语和关键句——高频词、观点句（某人认为、专家指出）、转折词（但、然而）后面必出点。第三步 加工：把意思相同的点合并，每条前面加一个自拟的概括词（如「党建引领」「社会参与」）。第四步 成文：总起句 + 分条罗列，一条一行，格式为「一是概括词＋具体阐述」。字数不够就删例子的细节，绝不删要点。
第三课 · 应用文模板（送分题）
应用文（提纲、公开信、短评、报告等）本质还是概括题＋格式分。格式只记三样：标题居中、正文分段、落款靠右（题目没要求落款就不写，别画蛇添足）。正文万能三段：开头一句话交代背景/目的，中间分条写要点（占 80% 篇幅，全部来自材料），结尾一句呼吁或总结。执法卷爱考的「工作指南」「情况报告」，照「总体要求→具体事项→保障措施」的顺序排材料要点即可。
第四课 · 大作文保底写法
不会写作文就背这个骨架——五段三分式：开头（150 字）引材料+亮总论点；中间三段，每段一个分论点，段式固定「分论点句 + 材料案例改写 + 两句道理分析 + 回扣句」；结尾（100 字）升华。立意从题干关键词里找，题目给了一句话，就围绕这句话拆出 2-3 个关键词当分论点；分论点的案例直接改写材料里的例子（换个说法，不抄原句）。开头结尾不会写，背 2 个万能模板就够用（本 app 每篇作文的【开头示范】都可以直接背）。做到结构完整、立意不跑、字数达标，就是稳稳的二类文。
第五课 · 每日训练法（关键中的关键）
申论进步靠「精做」不靠刷量：每天只做 1 道小题——先自己写，再打开本题的「写作解析」对照【怎么写】检查自己的步骤，最后看「参考答案」逐句找差距：它有的点我没有（漏点）、我有的点它没有（废话）、概括词谁更准。把差距写进本题的「我的备注」，三天后重做一遍。坚持 20 天，小题找点的手感就形成了。大作文每周完整写 1 篇即可，其余时间只练列提纲（10 分钟一篇）。
附 · 常见丢分点自查
①把对策写成问题（题问「变化」却答「做法」）——审题先答「对象是什么」；②直接抄材料原句不加工——概括词前置才能拿结构分；③漏了转折词后面的内容——「但」字之后是命题人真正想考的；④字数超格——先删例子的形容修饰，不动要点；⑤大作文跑题——写之前用一句话把总论点写在草稿纸上，每段结尾回看这句话。

方法课 · 采分点实战手册

第一讲 · 作答七条铁律
① 字数踩到题目要求的 85%-95%——格子数背后是采分点密度，写太短=漏点；② 每条要点用「动宾结构」开头，删掉「应该」「必须」「要」等情态动词，直接「健全机制」「压实责任」；③ 删水词：「进一步」「大力」「切实」「不断」等不改变信息量的修饰一律砍掉；④ 概括词必须来自材料原文或同义提炼，禁止凭空发明——材料说「局区合一」，你就写「局区合一」，不要自创「部门融合」；⑤ 对策题不重复问题细节，只答「怎么做」；⑥ 不写没有采分点的过渡句、喊口号句——归纳概括题不写总括句，综合分析题才写；⑦ 每写完一句自检：这句是采分点吗？不是就删。
第二讲 · 采分点覆盖法（估分）
对完参考答案，把它的要点当「采分点清单」逐条核对自己的答案：覆盖 ≥80% → 满分档；覆盖 40%-80% → 一半分；<40% → 基本不得分。用本 app 做题时，对照后按这个标准自评「答到了 / 没答到」。字数超标只扣表达分、不扣采分点分——先保点，再顺句。覆盖不到 80%，就把漏掉的点用「我的备注」标回材料出处（第几段、哪个关键词），三天后重做这道题再核对一遍。
第三讲 · 失分八维自查表
每道自评「没答到」的题，按这八个维度归因：找点（漏采分点 / 找错段落 / 自我脑补材料没有的 / 没用材料原词）；归并（没有统一句式 / 分类混乱 / 条数不当）；结构（该写总括句没写、不该写却写了 / 层次不分明）；要素（漏了题干要求的要素 / 对策没有来源）；表述（口语化 / 字数违规 / 没落实形式要求）；立意（大作文偏题 / 标题与论点不一致 / 论点虚化）；论证（只举例子不讲道理 / 素材陈旧烂大街）。归因后对症下药：知识盲区→回方法课重学；技巧不熟→同类题多练三道；粗心大意→写进备注当自查清单；时间不够→限时训练提速。
第四讲 · 表述升级 · 动词替换
口语动词升级为阅卷人爱看的规范表述：解决问题→破解难题 / 补齐短板 / 疏通堵点；加强→健全 / 完善 / 压实责任；推进→纵深推进 / 一体推进 / 统筹推进；做好→做实做细 / 落地见效；提高→提质增效 / 持续优化；重视→摆在突出位置 / 挂图作战；开展→组织实施 / 部署开展；形成→构建……格局 / 健全……机制。替换原则：换掉后信息量不减、字数相当，别为了高级而高级。
第五讲 · 高频成语与金句库
小题结尾、大作文过渡可用的稳档成语：久久为功、攻坚克难、夯基垒台、行稳致远、系统集成、协同高效、靶向施策、疏堵结合、蹄疾步稳、慎终如始。金句按主题背两句即可——民生：「治国有常，而利民为本」「民之所忧，我必念之；民之所盼，我必行之」；实干：「道虽迩，不行不至；事虽小，不为不成」「犯其至难而图其至远」；改革攻坚：「越是艰险越向前」「改革关头勇者胜」；基层治理：「基层强则国家强，基层安则天下安」。提醒：金句只在开头结尾各用一句，通篇堆砌反而降档——阅卷人要的是采分点和清晰结构，不是文学赏析。
